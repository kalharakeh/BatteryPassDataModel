Normal users can open the detailed report for their own cluster battery only. The customer account `customer_001_001@customer.org` can open North batteries including `CP7M-NORTH-001`; it should not open South, Fleet, Demo API, or unassigned detailed reports.

Local admin users can open `/cluster-admin` and edit only the fields selected by the general admin under **Local editable fields**. The default editable set is Facility ID, Battery image, State of charge %, Remaining capacity %, Remaining energy kWh, and Full cycles.

## Compatibility Search Alias

The old sample ID `did:web:acme.battery.pass:sample-customer-north-001` is kept as a compatibility alias. After reset, searching that alias should resolve to the generated Demo API battery and its latest passport; it is not the stored Battery ID anymore.

## Battery Family Reset

Press **Reset battery-family passports** on `/admin/clusters?tab=products` or `/admin/help` to recreate eight batteries and nine passport snapshots: one unassigned demonstrator, one Demo API battery with two passports, and six customer/fleet batteries. The reset removes older sample/demo passports so the acceptance test set stays small and predictable.
