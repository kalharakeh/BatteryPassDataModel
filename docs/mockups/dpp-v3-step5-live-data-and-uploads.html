Step 5 — uploads on each battery's page

Mock-up only; nothing here is built yet. It replaces the earlier central "Uploads" tab (the product owner, 2 Nov 2026): a file is uploaded on the page of the battery it is for, by the team or the battery's cluster admins. It uses the app's own stylesheets; site.css is not changed.

  1. 5c"Upload a file" on both battery pages, the check before saving, Save, and the battery's earlier uploads.
  2. 5dStatus changes and repairs by upload, shown in the same check (dashed).

Faded cards are the page's existing cards, for where the new card sits.

5cB1 · The team's battery page: "Upload a file"

A new card after "Measured on the battery". One JSON file for this battery: the app's upload format, or the battery system's export as it is. "Check the file" saves nothing. The modules card loses its own "Fill from export": an export sets the module list through this card. Earlier uploads of this battery are listed under the button, newest first, each opening in place.
