The detail page: one tab per audience, and where each value came from

Mock-up for step 3b. The detail page keeps today's look: the battery card at the top (not shown here), then tabs. The tabs start with one per audience the reader may see (purchaser, shared, authorities), marked with a lock and opened first; then come the public data by section, as on the public summary, with shorter tab names. Under each value, a small grey line says when it was generated and where it came from. Who sent it isn't shown.

1. The battery's cluster, on the Purchaser tab

A cluster user of the battery's cluster sees the Purchaser and Shared tabs, and the page opens on Purchaser; market surveillance and the team also see Authorities. A reader with no audience tab (for example another cluster) opens on Passport. Live values say "Measured"; everything else says "Entered". "Accident information" opens the battery's accident page.

An older version opened by its own passport ID. Its status is "Archived", with a link to the current version at the top (as today's "Historical passport"). Live values aren't kept per version, so its Purchaser tab says where to find them. A value that has changed since has no line, because its origin is no longer known.
